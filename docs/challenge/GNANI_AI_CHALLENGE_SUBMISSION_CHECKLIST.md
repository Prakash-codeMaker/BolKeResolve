# Great Indian AI Internship Challenge — final checklist

Official page reviewed 22 October 2026: https://www.gnani.ai/internship

## Eligibility

- [ ] Primary participant is 18+ on registration day and currently enrolled in an India-based college/university degree or course.
- [ ] If team submission, only one teammate is included (maximum team size two) and each member meets eligibility/accepts terms.
- [ ] Only one entry is submitted for the participant/team.

## Product and model

- [ ] Project title: `BolKeResolve: Hinglish Voice-to-Resolution Passport` (or a final title used consistently everywhere).
- [ ] A real working app is recorded, not only a mockup, slide deck or prototype video.
- [ ] The demo includes a live successful Prisma v2.5 transcription API call.
- [ ] If Timbre v2.5 is claimed, show a live successful TTS response/playback; otherwise don't claim it worked live.
- [ ] Model/API names and each person's actual contribution are listed in the submission.
- [ ] The value beyond transcription is visible: reviewed facts, scenario-specific official-source next step, support draft and saved/exportable passport.
- [ ] No invented bank verification, fabricated success, false user claim or implied official partnership.

## Demo and public post

- [ ] Record with synthetic data only; no real phone numbers, bank/account numbers, Aadhaar/PAN, private screenshots or unauthorised recordings.
- [ ] Video clearly identifies the project and Gnani model/API.
- [ ] Post is public on LinkedIn and/or X before submission.
- [ ] Tag Gnani AI's official account.
- [ ] Include both `#GnaniAI` and `#GreatIndianAIInternshipChallenge`.
- [ ] Nominate the exact post URL for each platform used.
- [ ] Do not use bought engagement, bots, paid promotion, engagement swaps or plagiarism.

## Submission assets

- [ ] Written project explanation based on `GNANI_AI_CHALLENGE_PLAYBOOK_2026.md`.
- [ ] Public demo video/post URL(s).
- [ ] Exact model/API list.
- [ ] Accurate contribution statement for each member.
- [ ] Submit before **10 November 2026, 11:59 PM IST** (as stated on official page as checked 22 October 2026).
- [ ] Recheck current official rules before final submission.

## Build quality

- [ ] `python -m pytest -q`
- [ ] `node --check frontend/app.js`
- [ ] Test one Hinglish clip and one pinned-language clip against live Prisma.
- [ ] Confirm corrected transcript is the one used to build the case.
- [ ] Confirm user-supplied amount/date are labelled as reported until confirmed.
- [ ] Confirm source links open and case export/print works.
- [ ] Confirm no credentials in source, commits, console output or video.
- [ ] Confirm failure path when key/API/quota is unavailable.
