## What to do before recording

1. Confirm that you meet the published eligibility rules: 18+ and currently enrolled in a college/university course in India. Team size is solo or two people maximum.
2. Register with the same email used for the Gnani API platform and obtain your programme API access/credits as directed in the official challenge instructions.
3. Put the valid key in the server environment as `GNANI_API_KEY`. Never include it in frontend code, source control, screenshots, logs shared publicly or the video.
4. Run the app locally. Execute `python -m pytest -q` and `node --check frontend/app.js`.
5. Make one real successful Hinglish/English-mixed Prisma transcription call. Confirm the returned transcript appears in the UI and is editable. If you wish to show Timbre, confirm a real successful TTS call and audible output; otherwise don't claim live Timbre in the public demo.
6. Record the demo with synthetic case data. Show the transition from spoken words to reviewed case facts, official-source next action and Resolution Passport.
7. Publish the video publicly on LinkedIn and/or X, tag Gnani AI's official account, add `#GnaniAI` and `#GreatIndianAIInternshipChallenge`, and nominate the exact published post link in the submission.
8. Final submission deadline on the official page as reviewed 22 October 2026: **10 November 2026, 11:59 PM IST**. Recheck the official page before submitting.

## Important

The project code contains actual HTTP adapters for Prisma and Timbre, but contract tests mock the provider. I do not have the contestant's API credential in this project session, so live transcription/playback must still be run and verified by the participant. The app does not independently verify bank transactions, submit complaints automatically, or guarantee refunds. Never use real personal or payment secrets in the demo.
